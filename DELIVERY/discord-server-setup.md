# 2D RPG Discord Setup

## Server

- Name: `2D RPG | Development Hub`
- Description: Development updates, playtest coordination, feedback, and support for the 2D RPG project.
- Default language: English
- Verification: Medium
- Explicit media filter: Scan all members

## Roles

| Role | Permissions |
| --- | --- |
| Admin | Full server management; assign only to project owners |
| Developer | Manage channels, post announcements, moderate playtests |
| Playtester | Post feedback, attach screenshots, join playtest voice |
| Member | Read public channels and join public voice |

## Channels

### INFORMATION

- `#announcements`: developer-only posting; releases, maintenance, and playtest dates.
- `#rules`: read-only; conduct, spoiler, and reporting guidance.
- `#roadmap`: read-only; current milestone status.

### COMMUNITY

- `#general`: project discussion.
- `#feedback`: structured feedback; ask members to include build version, steps, expected result, and actual result.
- `#bug-reports`: one issue per post; request reproduction steps, platform, and screenshot/video when available.
- `#screenshots`: gameplay media and art previews.
- `#support`: installation and control help.

### VOICE

- `Playtest Lobby`: scheduled group tests.
- `Development`: project discussions.

## First pinned post

Welcome to the 2D RPG development hub. Check `#announcements` for build and playtest updates. When reporting a bug, include the build version and steps to reproduce it. Keep feedback constructive and mark story spoilers clearly.

## Launch checklist

- Create the server and channels above.
- Set permissions so only Developers can post in announcement, rules, and roadmap channels.
- Add the final project logo and invite link.
- Add a moderation bot only after reviewing its permissions.
- Publish the first announcement with the current build version and project contact.
- Test the invite link with a non-admin account.
